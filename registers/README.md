# Registers

Four living documents. The distinction matters:

- **open-points.md** — questions that are actually unresolved, with how each would
  be settled. Severity-ranked. This is the working list.
- **open-points-archive.md** — settled questions, with the answer *and the
  evidence*. Consulted when something looks reopenable.
- **ideas.md** — the dump. No obligation, no ordering. Write here first.
- **rejected.md** — tried and cut, with reasons and numbers. The most useful of the
  four, because rejected ideas come back looking attractive and this is the record
  of why they were wrong.

The flow: idea → open point → rule or rejection.
